# **Firefly Headless CMS Testing Website**

This website serves as a testing ground for the Firefly Headless CMS. The primary objective of this project is to evaluate the feasibility of using Firefly CMS and later use it to create automated landing pages powered by ChatGPT.

## **Getting Started**

To start using this application, follow the steps below:

### **Prerequisites**

Ensure you have the following installed on your machine:

- Node.js (version 14.x or higher)
- NPM or Yarn (latest stable version)

### **Installation**

1. Clone the repository:

```bash
git clone https://github.com/yourusername/firefly-cms-testing-website.git
```

2. Navigate to the project folder:

```bash
cd firefly-cms-testing-website
```

3. Install the dependencies:

```bash
# Using NPM
npm install

# Using Yarn
yarn
```

### **Running the application**

To start the application in development mode, run:

```bash
# Using NPM
npm run dev

# Using Yarn
yarn dev
```

This will start the development server at `http://localhost:3000`.

## **About the Application**

This application is built using Nuxt.js, Vuetify, and Vue 3, and demonstrates how to integrate Firefly CMS with a Vue application for dynamic content management.

As you explore the application, you will see how Firefly CMS can be used to manage various aspects of the website, such as the header, the main content, and the various components in between.
